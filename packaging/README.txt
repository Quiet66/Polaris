Polaris（北极星）使用说明
========================

Polaris 是一块始终置顶、没有边框的小画布，用来在查资料时随手记下
“从哪查到哪”：一个节点是一段文字，一条连线表示两者有关联。
完全离线，不联网，不写注册表，解压即用。

运行：双击 polaris.exe。
系统：Windows 7 SP1 及以上（32 位、64 位都可以）。


一、最常用的几个操作
--------------------

  双击空白处          新建一个节点，直接打字
  Enter               确认
  Tab                 以当前节点为起点，再建一个相连的节点（可以一路按下去）
  拖动节点            移动；连线会跟着走
  滚轮                缩放
  空格 + 左键拖动     平移画布（也可以用鼠标中键拖动）
  Ctrl+S              保存

窗口没有标题栏。左上角有一个小圆点：
  单击    打开菜单
  拖动    移动窗口
  双击    最大化 / 还原
也可以按住 Alt 再用左键在画布任意位置拖动来移动窗口。

关闭窗口（Alt+F4）只是把它收进右下角的托盘，程序还在运行。
要真正退出，请用菜单里的“退出”。


二、节点
--------

  双击空白处                  新建节点并开始编辑
  双击节点，或选中后按 F2     编辑文字
  选中一个节点后按 Tab        新建相连的节点（方向：原节点 → 新节点）
  编辑时 Enter                确认
  编辑时 Shift+Enter          换行
  编辑时 Esc                  放弃这次修改
  编辑时 Tab                  确认，并接着再建一个相连的节点
  确认时文字是空的            这个节点会被删除
  拖动选中节点的左右两条边    调整宽度，文字自动换行
  Ctrl + =  /  Ctrl + -       放大 / 缩小选中节点的字号
  Ctrl + 0                    字号恢复默认
  Delete 或 Backspace         删除选中的节点（连同和它相连的线）


三、连线
--------

  鼠标移到节点上              节点四边出现小圆点（连接点）
  从连接点拖到另一个节点      连一条线
  从连接点拖到空白处          在那里新建一个节点并连线
  单击连线                    选中它
  选中连线后按 Delete         只删这条线，两头的节点不受影响

两个节点之间最多一条线。菜单里的“连线方向”可以关掉箭头。


四、画布与选择
--------------

  单击节点                    选中
  Shift + 单击                加选 / 减选
  在空白处拖动                框选
  单击空白处                  取消选择
  Ctrl+A                      全选
  滚轮                        以光标为中心缩放（20% ～ 300%）
  Ctrl+1                      缩放到能看到全部节点
  Ctrl+Z  /  Ctrl+Y           撤销 / 重做


五、文件
--------

  Ctrl+N                      新建
  Ctrl+O                      打开
  Ctrl+S                      保存
  Ctrl+Shift+S                另存为
  菜单 → 导出图片             导出 PNG（在“保存类型”里选带背景或透明背景）

文件保存为 .md（Markdown）。用记事本或任何 Markdown 软件打开，
能直接看到一份大纲；文件最后一行是 Polaris 用来还原画面的布局信息，
请不要改动或删除它，否则 Polaris 将无法再打开这个文件。

内容有改动时，Polaris 每隔几秒会自动存一份草稿。如果程序被意外关闭，
下次启动时会问你要不要恢复。


六、全局快捷键（在任何程序里按都有效）
--------------------------------------

  Ctrl+Alt+空格               隐藏 / 唤出窗口
  Ctrl+Alt+T                  切换“窗口置顶”
  Ctrl+Alt+↑                  窗口更不透明（每次 10%）
  Ctrl+Alt+↓                  窗口更透明（每次 10%，最低 30%）

如果某个快捷键和别的软件冲突，启动时会有提示。


七、改成自己顺手的操作方式
--------------------------

菜单 → “快捷键与鼠标设置”，可以修改：

  拖动画布    空格+左键（默认）、右键、中键、Ctrl+左键、Alt+左键
  拖动窗口    Alt+左键（默认）、Ctrl+左键、右键、中键、空格+左键，或不启用
  上面四个全局快捷键

菜单里还可以切换：背景（纯色 / 点阵 / 线阵）、主题（浅色 / 深色）、
连线方向、精简动效、窗口置顶、透明度。这些设置都会被记住。


八、设置存在哪里
----------------

设置和草稿保存在程序所在文件夹的 data 子文件夹里。
如果该位置不允许写入，会改存到 %APPDATA%\Polaris。
想恢复成初始状态：先退出 Polaris，再删掉 data 文件夹即可。
把整个文件夹拷到别的电脑或 U 盘上，设置会跟着走。
